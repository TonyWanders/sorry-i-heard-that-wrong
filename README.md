A program that writes one funny one-line apology from a smart speaker to
`/output/entry.txt`, for the make.fun competition
[Sorry, I Heard That Wrong](https://make.fun/bounty/u-kiencx-sorry-i-heard-that-wrong-1858c729).

Run it with Python 3:

```
python3 main.py
```

It writes the line below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The line is 114 characters, inside the 1 to 140 gate.

## The entry

```
Sorry, I heard 'dim the lights' as 'delete the flights', so your honeymoon is cancelled but the room looks lovely.
```
